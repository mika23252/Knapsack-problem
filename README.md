# 0/1 Knapsack Problem

**Групповой проект, выполнена часть с решением задачи через генетический алгоритм NSGA-II.**
<br>В репозитории представлены две C++-реализации задачи о рюкзаке с ограничением вместимости:

1. Динамическое программирование — поиск одного оптимального решения.
2. Генетический алгоритм NSGA-II — поиск множества компромиссных решений по двум критериям.

Для визуализации используется **SFML 2.6.2**.

## 1. Динамическое программирование

Исходный файл: `dynamic/main.cpp`.

Решается классическая задача о рюкзаке 0/1: каждый предмет либо выбирается целиком, либо не выбирается. Необходимо максимизировать суммарную ценность предметов при ограничении на общий вес.

Используется таблица динамического программирования:

- время работы — O(NM);
- дополнительная память — O(NM),

где N — количество предметов, а M — вместимость рюкзака.

Программа выводит максимальную ценность в консоль и открывает окно SFML с визуализацией таблицы состояний.

### Формат входных данных

Ввод осуществляется через стандартный поток:

1. количество предметов N и вместимость M;
2. N целых чисел — веса предметов;
3. N целых чисел — ценности предметов.

Пример:

```text
3 8
3 4 5
30 50 60
```

Для этого примера максимальная ценность равна **90**.

## 2. Генетический алгоритм NSGA-II

Исходный файл: `genetic/genetic/genetic_graph.cpp`.

В этой реализации задача рассматривается как многокритериальная: требуется одновременно **максимизировать суммарную ценность** и **минимизировать суммарный вес** выбранных предметов.

В коде реализованы основные этапы NSGA-II:

- кодирование решения бинарным вектором;
- генерация начальной популяции;
- одноточечное скрещивание;
- побитовая мутация;
- сортировка по недоминируемости;
- отбор с использованием crowding distance.

Параметры и тестовый набор предметов заданы непосредственно в исходном файле:

| Параметр | Значение |
| --- | ---: |
| Вместимость рюкзака | 30 |
| Размер популяции | 20 |
| Число поколений | 100 |
| Вероятность мутации гена | 0.3141592 |
| Число предметов | 10 |

После выполнения программа выводит пары «ценность — вес» для решений фронта Парето и отображает их на графике SFML. Генератор случайных чисел инициализируется текущим временем, поэтому результаты разных запусков могут отличаться.

## Структура проекта

| Каталог / файл | Назначение |
| --- | --- |
| `dynamic/` | Реализация задачи методом динамического программирования |

## Сборка

Обе реализации оформлены как отдельные проекты Visual Studio:

- для динамического программирования откройте `dynamic/0-1_Knapsack_Problem.sln`;
- для NSGA-II откройте `genetic/genetic.sln`.

Для обеих программ требуется совместимая с проектом версия **SFML 2.6.2**. В настройках проектов указаны локальные абсолютные пути к SFML, поэтому перед сборкой их может потребоваться изменить на пути в вашей системе.

В проектах используются разные настройки компилятора:

- `dynamic` — toolset `v143` (Visual Studio 2022); настройки SFML прописаны для `Debug|x64`;
- `genetic` — toolset `v142` (Visual Studio 2019); настройки SFML прописаны для конфигураций `Win32` и используют статические библиотеки.

Выберите конфигурацию, для которой настроены пути к заголовочным файлам и библиотекам SFML. При запуске убедитесь, что рабочий каталог содержит соответствующий файл шрифта (`arialmt.ttf` для динамической реализации или `arial.ttf` для генетической). Для динамической сборки также должны быть доступны необходимые DLL SFML.

## Примечания

- Динамическая реализация принимает параметры задачи через консольный ввод.
- Генетическая реализация использует фиксированный набор предметов и параметры, заданные в исходном коде.
- Визуализация динамического программирования выводит таблицу значений, а NSGA-II — приближение фронта Парето; эти представления соответствуют разным постановкам задачи.
